# 📊 AI Data Analyst

[![CI](https://github.com/kallurayaankit/ai-data-analyst/actions/workflows/ci.yml/badge.svg)](https://github.com/kallurayaankit/ai-data-analyst/actions/workflows/ci.yml)

A natural language → SQL → database → chart system that lets you ask questions in plain English and get back SQL, results, visualizations, and explanations.

---

## 🔍 Features

- **Natural language to SQL** using a local LLM (Mistral via Ollama)
- **SQL validation** – read‑only queries, injection protection, dangerous keyword blocking
- **Query timeout** – prevents long‑running queries
- **Retry / revision loop** – automatically corrects SQL errors
- **Result formatting** – structured for charting and interpretation
- **Chart generation** – automatically creates bar charts when appropriate
- **Natural language explanation** – summarizes insights from the results
- **Caching** – avoids repeated queries
- **Token / cost tracking** – shows usage statistics
- **Evaluation dataset** – benchmark questions to measure accuracy

## ⚡ Quick Start (Local)

### 1. Set up environment
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
2. Create the sample database
bash

python create_db.py

3. Run the Streamlit app
bash

streamlit run app.py

Open http://localhost:8501 and ask questions like:

    "Show total revenue by country"

    "How many orders were placed in the last 30 days?"

    "What is the average order amount by month?"

🛡️ Security & Safety

    Database is accessed in read‑only mode (PRAGMA query_only = ON)

    Dangerous SQL keywords are blocked (INSERT, UPDATE, DELETE, etc.)

    Queries are limited to 100 rows

    Execution timeout prevents resource abuse

🤖 Tech Stack

    Python 3.12

    Streamlit – UI

    Ollama (Mistral) – LLM for SQL generation and explanations

    SQLite – database

    Plotly – charting

    Requests – Ollama API communication

📬 Example Output

Question: Show revenue by country this month

Generated SQL:
sql

SELECT country, SUM(amount) as Revenue
FROM orders
JOIN customers ON orders.customer_id = customers.customer_id
WHERE strftime('%Y-%m', order_date) = strftime('%Y-%m', 'now')
GROUP BY country
LIMIT 100;

Results:
country	Revenue
Germany	93.54
India	174.23
UK	883.72

Explanation:
This SQL query provides a summary of revenue generated by customers from different countries for the last one month. Germany, India, and the UK are among the top three countries with the highest revenue.

## 6. Add GitHub Actions workflow for the green badge

Create the workflow file:

```cmd
mkdir .github\workflows
notepad .github\workflows\ci.yml

Paste this content:
yaml

name: Validate AI Data Analyst

on:
  push:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v4
        with:
          python-version: '3.12'
      - name: Install dependencies
        run: pip install -r requirements.txt
      - name: Check Python syntax
        run: |
          python -m py_compile app.py
          python -m py_compile nl2sql.py
          python -m py_compile create_db.py
